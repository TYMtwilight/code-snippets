RESTコントローラーの主要アノテーション

  • 📅 作成日: 2026-09-21
  • 🔄 更新日: 2026-09-21

🎯概要

@RestControllerを中心に、パスの切り方(@RequestMapping)、HTTPメソッドの振り分け(@GetMapping/@PostMapping)、パラメータの受け取り方(@PathVariable/@RequestParam/@RequestBody)の役割分担を整理する。

@RestController

@Controller + @ResponseBody の合成。戻り値を自動的にJSONへシリアライズしてレスポンスボディに書き込む。画面(View)を返さないAPI専用コントローラーであることを明示する。

@RestController
public class SnippetController { ... }

@ResponseBody

メソッドの戻り値をHTTPレスポンスボディにそのまま書き込む(ビュー名として解決しない)ことを示す。@RestControllerはこれをクラス全体に適用した合成アノテーションなので、通常は個別に付ける必要はない。

@Controller
public class SnippetController {

    @GetMapping("/{id}")
    @ResponseBody
    public SnippetReviewDto getById(@PathVariable Long id) {
        return snippetService.findById(id);
    }
}

@RequestMapping("/api/snippets")

クラスに付けることで、そのコントローラー内の全エンドポイントに共通のベースパスを設定する。

@RequestMapping("/api/snippets")
public class SnippetController { ... }

@GetMapping / @PostMapping

@RequestMapping(method = ...)の短縮形。HTTPメソッドごとにハンドラメソッドを分ける。

@GetMapping("/{id}")
public ResponseEntity<SnippetReviewDto> getById(...) { ... }

@PostMapping
public ResponseEntity<SnippetReviewDto> create(...) { ... }

@PathVariable

URLパスの一部(/snippets/42の42)を受け取る。リソースを一意に識別するIDなど、「そのURL自体の一部」を表す値に使う。

// GET /api/snippets/42
@GetMapping("/{id}")
public ResponseEntity<SnippetReviewDto> getById(@PathVariable Long id) {
    return ResponseEntity.ok(snippetService.findById(id));
}

@RequestParam

クエリパラメータ(?tag=spring&page=0)を受け取る。検索条件・フィルタ・ページングなど、任意/省略可能な値に使うことが多い。

// GET /api/snippets?tag=spring&page=0
@GetMapping
public ResponseEntity<List<SnippetReviewDto>> search(
        @RequestParam(required = false) String tag,
        @RequestParam(defaultValue = "0") int page) {
    return ResponseEntity.ok(snippetService.search(tag, page));
}

@RequestBody

リクエストボディのJSONを、Jacksonを介してJavaオブジェクト(DTO)に変換する。作成・更新系のPOST/PUTでよく使う。

// POST /api/snippets
@PostMapping
public ResponseEntity<SnippetReviewDto> create(@Valid @RequestBody SyncRequestDto request) {
    SnippetReviewDto created = snippetService.create(request);
    return ResponseEntity.status(HttpStatus.CREATED).body(created);
}

💡 使い分けの目安

そのリソースを特定するためのIDか?

→@PathVariable

GET /api/snippets/42

絞り込み・並び替え・省略可能なオプションか?

→@RequestParam

GET /api/snippets?tag=spring&page=0

作成・更新するデータ本体か?

→@RequestBody

POST /api/snippets
Body: { "title": "...", "code": "..." }

💻コード

@RestController
@RequestMapping("/api/snippets")
public class SnippetController {

    private final SnippetService snippetService;

    public SnippetController(SnippetService snippetService) {
        this.snippetService = snippetService;
    }

    @GetMapping("/{id}")
    public ResponseEntity<SnippetReviewDto> getById(@PathVariable Long id) {
        return ResponseEntity.ok(snippetService.findById(id));
    }

    @GetMapping
    public ResponseEntity<List<SnippetReviewDto>> search(
            @RequestParam(required = false) String tag,
            @RequestParam(defaultValue = "0") int page) {
        return ResponseEntity.ok(snippetService.search(tag, page));
    }

    @PostMapping
    public ResponseEntity<SnippetReviewDto> create(@Valid @RequestBody SyncRequestDto request) {
        SnippetReviewDto created = snippetService.create(request);
        return ResponseEntity.status(HttpStatus.CREATED).body(created);
    }
}

コード解説

  1. @RestController
@RequestMapping("/api/snippets")
public class SnippetController {

    @RestControllerでこのクラスをREST用のコントローラーとして登録し、各メソッドの戻り値をJSONとしてレスポンスボディに書き込む。@RequestMapping("/api/snippets")でクラス全体の共通パスを固定し、以降の各メソッドのパスはこれに追加される形になる。

  2. private final SnippetService snippetService;

public SnippetController(SnippetService snippetService) {
    this.snippetService = snippetService;
}

    ビジネスロジックを担うSnippetServiceをフィールドとして保持し、コンストラクタインジェクションでSpringに注入してもらう。

  3. @GetMapping("/{id}")
public ResponseEntity<SnippetReviewDto> getById(@PathVariable Long id) {
    return ResponseEntity.ok(snippetService.findById(id));
}

    GET /api/snippets/{id}宛のリクエストを割り当てる。URLパスの{id}部分を@PathVariableでLong idとして受け取り、取得したデータをステータス200(OK)とともに返す。

  4. @GetMapping
public ResponseEntity<List<SnippetReviewDto>> search(
        @RequestParam(required = false) String tag,
        @RequestParam(defaultValue = "0") int page) {
    return ResponseEntity.ok(snippetService.search(tag, page));
}

    ベースパス/api/snippetsそのものへのGETリクエスト(検索用)を割り当てる。クエリパラメータ?tag=...は@RequestParam(required = false)で省略可能な値として、?page=...は@RequestParam(defaultValue = "0")で省略時に0となる値として受け取り、検索結果を一覧(List)で200とともに返す。

  5. @PostMapping
public ResponseEntity<SnippetReviewDto> create(@Valid @RequestBody SyncRequestDto request) {
    SnippetReviewDto created = snippetService.create(request);
    return ResponseEntity.status(HttpStatus.CREATED).body(created);
}

    POST /api/snippets宛のリクエスト(新規作成)を割り当てる。リクエストボディのJSONを@RequestBodyでSyncRequestDtoに変換し、@Validでバリデーションを実行してからサービスに登録処理を委譲し、作成成功を表すステータス201(CREATED)とともに作成されたリソースを返す。
